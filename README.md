# 横文字御法度(よこもじごはっと)

**カタカナ語・英語を使わずにお題を説明する、ブラウザで遊ぶパーティゲームです。**

「アジェンダ」「エビデンス」「サブスクリプション」などのカタカナ語を、日本語だけで仲間に伝えます。うっかり横文字を口にしたら「御用」です。

スマホ1台を順番に回して遊ぶ形式です。インストールは要らず、`index.html` を開くだけで動きます。

---

## 遊び方

1. **お題の種類**と**持ち時間**を選んで「開始」を押します。
2. 説明役に端末を渡します。ほかの人は画面を見ないでください。
3. 説明役が「封を切る」を押すと、お題が出ます。
4. 説明役は、英語もカタカナ語も使わずにお題を説明します。
5. 判定はプレイヤー同士で行い、ボタンを押します。
   - **当たり**:誰かが正解した(1点)
   - **見送る**:そのお題を飛ばす
   - **横文字を口にした(御用)**:説明役が横文字を言ってしまった(そのお題は失格)
6. 時間が切れたら結果発表です。次の説明役に端末を渡して、次の幕へ進みます。

### 定(ルール)

> 一、説明役はひとり。お題を確かめ、仲間に言葉で伝えるべし
> 二、英語・カタカナ語は一切御法度。お題の言葉も然り
> 三、口にした者は「御用」となり、その題は失格とす
> 四、当てたら一点。時が尽きるまで続けるべし

## 主な機能

| 機能 | 内容 |
|---|---|
| お題 450題 | 仕事の言葉 180題、情報の言葉 135題、日々の言葉 135題。ごちゃまぜも選べます |
| 持ち時間 | 60秒 / 120秒 / 180秒 / なし |
| 説明の手本 | 全お題に横文字を使わない説明例が付いています。詰まったときだけ開けます |
| 出題の偏り防止 | ページを開いている間、一度出たお題は未出題のお題をすべて出し切るまで出ません |
| 結果発表 | 点数、称号、当たり・見送り・御用の内訳、お題ごとの手本使用の有無を表示します |
| 称号 | 見習い(0点)→ 丁稚(1点〜)→ 手代(3点〜)→ 番頭(6点〜)→ 大番頭(9点〜)→ 横文字奉行(12点〜) |
| 問題集の編集 | 全お題の一覧表示、追加、削除ができます。手本に横文字が混じっていると追加できません |
| 帳面の書き出し・読み込み | 編集した問題集をJSONファイルに保存して、次回読み込めます |
| 昼・夜の配色 | 端末のライトモードとダークモードに合わせて自動で切り替わります |
| 画面の消灯防止 | 対応ブラウザでは、遊んでいる間は画面が消えません |

## 起動方法

### パソコン・スマホで直接開く

`index.html` をブラウザで開くだけで遊べます。サーバーもビルドも要りません。

### GitHub Pages で公開する

1. このリポジトリを GitHub に上げます。
2. リポジトリの **Settings → Pages** を開きます。
3. **Branch** で `main` と `/ (root)` を選び、保存します。
4. しばらくすると `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります。

このURLをスマホで開いて「ホーム画面に追加」すると、アプリのように起動できます。

## お題の追加・変更

### 画面から(手軽)

ホーム画面の「問題集を検める」から、お題を追加・削除できます。

ただし、画面で編集した内容はページを閉じると消えます。残したいときは「帳面に書き出す」で JSON ファイルを保存し、次に遊ぶときに「帳面を読み込む」で読み込んでください。

### ソースコードから(恒久的)

`index.html` の中にある `const WORDS = { ... }` を編集します。お題は `[お題, 説明の手本]` の組で並んでいます。

```js
const WORDS = {
  business: [   // 仕事の言葉
    ["アジェンダ","会議で話し合う事柄を並べた一覧のこと"],
    ...
  ],
  it: [ ... ],      // 情報の言葉
  daily: [ ... ]    // 日々の言葉
};
```

手本の文にはカタカナや英字を使わないでください。

### 帳面(JSON)の形式

書き出したファイルは、次の形式になっています。この形式で作ったファイルなら読み込めます。

```json
{
  "business": [["アジェンダ", "会議で話し合う事柄を並べた一覧のこと"]],
  "it":       [["クラウド", "手元ではなく通信網の先の計算機に情報を預ける仕組み"]],
  "daily":    [["ランチ", "昼の食事のこと"]]
}
```

## 動作環境

- iPhone(Safari)、Android(Chrome)、パソコンの最近のブラウザで動きます。
- 書体は Google Fonts(しっぽり明朝、Zen角ゴシック New)を読み込んでいます。ネットにつながっていないときは、端末に入っている明朝体とゴシック体で表示されます。遊ぶことはできます。
